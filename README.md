# The-RTO-Dynamic-Friction-Engine
Built an end-to-end RTO risk case study for CoD e-commerce orders: synthetic 500K-order dataset, calibrated risk model (LogReg vs GBM, ROC-AUC 0.72), and a dynamic friction engine. Naive fee cut profit -2%; a risk-scored, LTV-guarded policy lifted it +5.5%. Shipped with PRD, A/B test design, and decision memo.
